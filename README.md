### Hillel Java Pro project
***
 ### Homework 39.1 Customer Spring JDBC practice
***
This homework provides an implementation of a **Customer** management system, allowing you to perform CRUD operations (Create, Read, Update, Delete) on customer data. It interacts with a database using **JdbcTemplate** for handling database operations, and the system is configurable to work with either **MySQL**.

**Features:**
- **Customer** class with fields: id, fullName, email, socialSecurityNumber.
- **CustomerDao** for database operations: add, update, delete, search by ID, and retrieve all customers.
- Configurable **JdbcTemplate** for database interaction.
- Mappers to convert database records into Java objects.
