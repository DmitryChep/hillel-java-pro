### Homework 31.1  Library Management System
***

This homework consists of two main classes: `Book` and `Library`.

- The **Book** class represents a book with attributes such as `title` and `author`.
- The **Library** class manages a collection of books, providing functionality to add, remove, and retrieve books, as well as checking the total number of books.
- 
**Features**
- Add a book to the library.
- Remove a book from the library.
- Get the list of all books in the library.
- Get the total number of books in the library.
