### Hillel Java Pro project
***
 ### Homework 38.1 Working with the online store cart
***
This is a console application that simulates a product management and shopping cart system. It allows performing CRUD operations on products and managing a shopping cart.

__Features:__
- **Product Management**: Add, retrieve, and remove products.
- **Shopping Cart**: Add and remove products by ID.
- Each time the cart is requested, a new instance is returned.
