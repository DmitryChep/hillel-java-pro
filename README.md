### Hillel Java Pro project
***
### Homework 42.1 Spring Data Jpa practice 
***
This homework demonstrates how to use Spring Data JPA to manage `User` and `Post` entities. Features include:

- Create and manage users with `name` and `email`.
- Find users by name or email domain (e.g., `@gmail.com`).
- One-to-many relationship between `User` and `Post`.
- Transactional service for creating users and posts.
- RESTful endpoints for CRUD operations.
- Configured for multiple databases: MySQL, PostgreSQL, H2.
