### Hillel Java Pro project
***
### Homework 43.1 Spring Security.
***
This homework demonstrates user authentication and authorization using **Spring Boot**, **Spring Security**, and **MySQL**. 
It implements user registration, login, and logout with password hashing and role management.

## Technologies

- **Spring Boot**
- **Spring Security**
- **Spring Data JPA**
- **MySQL**
- **Thymeleaf**
- **BCrypt**

## Key Features

- **User Registration**: Users can register through a form, and their passwords are hashed.
- **User Login**: Users can log in using their email and password.
- **Logout**: After logging in, users can log out using the "Logout" button.
- **User List**: After logging in, a list of registered users is displayed.
- **Security**: All passwords are hashed using **BCrypt**.
