### Homework 34.1 Interactive Calculator
***
This project is a simple calculator created using HTML, CSS, and JavaScript. It supports basic arithmetic operations and can evaluate mathematical expressions.

__Features:__
- Addition, subtraction, multiplication, division.
- Clear input (button "C").
- Delete the last character (button "←").
- Error handling (e.g., division by zero).

__Technologies:__
- HTML: Page structure.
- CSS: Calculator styling.
- JavaScript: Calculation logic and user interaction.
