***
### Homework 32.1 Coffee Order System
***
This homework simulates a coffee shop's order queue system. It contains the following components:

**Features**:
1. **Add Order**: Adds a new order with an automatically assigned number.
2. **Deliver Order**: Delivers the next order in the queue and removes it from the list.
3. **Deliver Specific Order**: Delivers an order based on its specific number and removes it from the list.
4. **Draw Queue**: Prints the current state of the order queue with order numbers and customer names.
5. **Logging**: Configured logging (using Logback or Log4j) that provides insights into the operations, with appropriate log levels.

 
**Logging:**

Logs are configured to print to the console, tracking the flow of operations and errors with proper log levels.
