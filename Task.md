Create an Interactive Calculator using HTML, CSS, and JavaScript. The calculator should support basic arithmetic operations (addition, subtraction, multiplication, division) and be able to evaluate simple mathematical expressions.**

1. HTML:
* Create the HTML structure for the calculator. Add buttons for digits, operations, and the result display.

2. CSS:
* Style the calculator for ease of use.

3. JavaScript:
* Implement the logic for evaluating expressions and displaying the result.  
* Add the ability to delete the last entered character (backspace).  
* Implement the functionality to clear all input (clear).  
* Handle division by zero and other edge cases.
